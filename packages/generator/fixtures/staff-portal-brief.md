Kapiko Bank — Staff Operations Portal (fictional demo) for onboarding and finance applications. Brand colours #17365D, #0E9389, #F58220. Desktop web portal with a left sidebar.

1. **Dashboard:** KPI tiles (open applications, pending maker, pending checker, approved this month), recent applications table with View.
2. **Customer Applications:** searchable table of applications (reference, customer, product, amount AED, emirate, status, submitted date) with status filter, CSV export and a View action per row.
3. **Application Details:** shows the selected application's customer and request details, documents status, and buttons for Maker Review and Checker Approval.
4. **Maker Review:** recommendation (approve / request information / reject), comments, submit to checker; the application status becomes Pending checker.
5. **Checker Approval:** shows the maker recommendation and comments; Approve, Return to maker or Reject; status updates.
6. **Completed Applications:** table of decided applications with View.
7. **Reports:** monthly turnaround, approval rate and finance volume figures (fictional).

Row View actions must open Application Details with the clicked application. Use 6-8 fictional UAE applications.
