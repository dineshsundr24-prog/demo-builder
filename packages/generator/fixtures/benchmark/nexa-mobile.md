Create a modern, premium digital banking mobile application named Nexa Digital Banking.

The application should have a professional banking UI with a navy-blue and teal color scheme, white backgrounds, rounded cards, clean typography, consistent icons and a realistic mobile layout.

Generate exactly 10 connected mobile screens with the following requirements.

Screen 1: Welcome

Display the Nexa Bank logo/name and welcome message.

Show two primary buttons: Sign In and Create Account.

Sign In navigates to Screen 2.

Create Account navigates to Screen 3.

Screen 2: Sign In

Mobile number or email input.

Password field.

Remember Me checkbox.

Sign In button navigates to Screen 6.

Create Account link navigates to Screen 3.

Forgot Password link can show a simulated information message.

Screen 3: Create Account

Full name, mobile number, email address and password.

Confirm password field.

Accept Terms and Conditions checkbox.

Continue button navigates to Screen 4.

Screen 4: OTP Verification

Six-digit OTP input.

Resend OTP option.

Verify button navigates to Screen 5.

Use simulated OTP verification; no real SMS integration.

Screen 5: Identity Verification

Show customer identity verification using a simulated UAE PASS journey.

Display verification checklist and document status.

Verify Identity button marks verification successful.

Continue button navigates to Screen 6.

Screen 6: Dashboard

Personalized greeting with the customer's name.

Account balance card displaying AED 48,750.50.

Savings account number displayed in masked format.

Quick actions: Transfer Money, Pay Bills, Service Requests and Profile.

Show recent transactions with dates, descriptions and AED amounts.

Include bottom navigation: Home, Transactions, Services and Profile.

Transfer Money navigates to Screen 7.

Pay Bills navigates to Screen 9.

Service Requests navigates to Screen 10.

Profile navigates to Screen 8.

Screen 7: Transfer Money

Display available account balance.

Beneficiary name input.

Beneficiary IBAN input.

Transfer amount input in AED.

Transfer purpose dropdown.

Review Transfer button displays a confirmation summary.

Confirm Transfer shows a simulated successful transfer message.

Provide a way to return to Dashboard.

Screen 8: My Profile

Display customer name, email, mobile number and masked Emirates ID.

Allow editing email and mobile number.

Save Changes button updates displayed profile data within the demo.

Provide navigation back to Dashboard.

Screen 9: Bill Payment

Bill category selection: Electricity, Water, Telecom and Internet.

Provider selection dropdown.

Consumer/account number input.

Payment amount input.

Pay Now button shows simulated payment confirmation.

Provide navigation back to Dashboard.

Screen 10: Service Requests

Display a list of existing service requests with reference numbers, dates and status.

Submit Request button adds a simulated request with status Submitted.

Allow navigation back to Dashboard.
