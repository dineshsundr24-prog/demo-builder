Kapiko Bank — mobile banking app (fictional demo).

Brand guidance: primary navy #17365D, secondary teal #0E9389, accent orange #F58220, light neutral backgrounds, mobile reference viewport 390 x 844. Build a complete connected application with exactly these 12 screens:

1. **Welcome:** Bank brand, introductory copy, Sign In and Create Account.
2. **Sign In:** Mobile/email, password, show/hide, forgot password, UAE PASS demo sign-in, links to sign-up and dashboard.
3. **Sign Up:** Name, UAE mobile +971, email, password/confirmation, terms consent; validate and continue to OTP.
4. **Mobile OTP Verification:** Six-digit OTP, masked number, countdown and resend (simulated); continue to eKYC.
5. **eKYC using UAE PASS:** Simulated authentication/Digital Vault retrieval, consent, sample Emirates ID and identity details, review and confirm.
6. **Face Verification:** Camera-frame placeholder, lighting guidance and simulated success; no actual camera/biometrics.
7. **Dashboard:** Ahmed Al Hammadi (fictional), AED 48,750 sample balance, account summary, notifications, activity, quick actions, top menu and footer.
8. **Income Update:** Existing employer/income, new salary/allowances/additional income, employment status, effective date, document upload, Save Draft/Continue/Cancel.
9. **Income Verification & Review:** Previous vs updated amounts, comparison, document status, simulated verification and consent; confirm submit.
10. **Income Update Confirmation:** Success, sample SR KPK-INC-2026-00125, status/date and View Request/Return Dashboard.
11. **My Service Requests:** List of requests with status and View Details; includes submitted income update.
12. **Customer Profile:** Sample identity/contact/employment/income/account fields with Edit Profile.

Journeys: Welcome → Sign Up → OTP → UAE PASS eKYC → Face Verification → Dashboard; Welcome → Sign In → Dashboard; Dashboard → Income Update → Income Verification & Review → Confirmation → My Service Requests; Dashboard → Profile. All Back, Continue, Submit, View and Cancel routes must resolve to existing screens.
